How to Create a Telegram Bot

  1. Open Telegram and search for @BotFather
  2. Send the command /newbot
  3. Choose a display name for your bot (e.g. "Nemo Tracker")
  4. Choose a username ending in bot (e.g. nemo_tracker_bot)
  5. BotFather will respond with your bot token — copy it into the field above
  6. To get your Admin ID: message @userinfobot on Telegram and copy the ID
  7. Send /setprivacy to BotFather, select your bot, then choose Disable so the bot can read group messages (optional)
